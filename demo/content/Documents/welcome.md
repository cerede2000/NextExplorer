# Welcome to the NextExplorer demo

Everything here is a scratch copy. **The whole thing resets whenever the demo
restarts**, so feel free to upload, rename, delete and move things around.

## Worth trying

- Right-click a file and choose **Move to** — the dialog offers recent
  destinations and favourites before any browsing.
- Open a picture, then swipe or use the arrow keys to move through the folder.
  Pinch, double-tap or ctrl-scroll to zoom.
- Drag a file onto a folder to move it; hold Alt or Option to copy instead.
- Star a folder in the sidebar, then drop files straight onto it.
- Upload something large and watch the transfer rate.

## What is not enabled here

The terminal is switched off, and so is sharing — a public demo is not a
file host.
